# 开源门面对标备忘（2026-09-05）

HandySwitch 第一次公开到 GitHub `x0c/HandySwitch` 时对照的高星同类与本仓决策。产品事实以本仓库为准。

| 对标项目 | 借鉴项 | 是否采用 |
|---|---|---|
| [jacklandrin/OnlySwitch](https://github.com/jacklandrin/OnlySwitch)（~6k★） | 首屏价值主张、安装靠前、真实界面图、功能表 | **部分**：用短功能列表，不做功能超市大表 |
| [Caldis/Mos](https://github.com/Caldis/Mos) | 徽章行、双语 README、Homebrew + Releases | **是**：安装双通道与徽章风格对齐 MacResourceMonitor |
| [x0c/MacResourceMonitor](https://github.com/x0c/MacResourceMonitor) | Supported platforms 声明、Not in scope、干净快照推公开仓、本机一条命令发版 | **是**：整套门面与发版骨架直接复用 |

刻意不抄：OnlySwitch 的 Shortcuts Gallery / Desktop Pet / 社区 Discord；Mos 的按应用配置与按钮重映射（产品已明确不做）。
